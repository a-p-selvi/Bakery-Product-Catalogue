## Project Overview
Maison de Douce is a luxury, modern, and elegant bakery product catalogue web application designed with a sophisticated Parisian patisserie brand identity. Built using vanilla HTML5, CSS3, and JavaScript, the project delivers a commercial-grade user experience with seamless responsiveness across mobile (360px), tablet (768px), and desktop (1366px) viewports.

---

## Features & Functionality
1. **Luxury Brand Identity & UI:** Warm cream (`#FAF6F0`), ivory (`#FFFDF9`), chocolate brown (`#2C221E`), soft beige (`#D9C5B2`), and muted gold (`#C5A059`) colour palette paired with *Playfair Display* and *Inter* typography.
2. **Dynamic Product Catalogue:** 8+ fictional artisanal products across Cakes, Pastries, Breads, Cookies, and Muffins rendered dynamically from a JavaScript array.
3. **Case-Insensitive Search & Filters:** Instant keyword search, category dropdown filter, reset button, and live matching product count with empty state handling.
4. **Product Details Modal:** Comprehensive modal view displaying high-resolution imagery, product ID, category, INR price (₹), and detailed description.
5. **Favourites with LocalStorage:** Add/remove favourite items with instant badge updates and persistent storage across page refreshes.
6. **Enquiry Form & Validation:** Client-side validation with inline error messages and a professional success preview notice.
7. **Internship Documentation Hub:** Built-in modal viewer containing the Project Plan, Wireframe Notes, Task Checklist, Test Report (10 checks), Progress Report, and README.
